### 権利条件の要約

**確認済み（上記ページの記載）:**

| 項目 | 御丹宮くるみ | 夏目悠李 | 波音リツ |
|---|---|---|---|
| DB を学習に使う | **記載なし** | **要確認**（下記の注） | **記載なし** |
| DB の再頒布 | **禁止**（ラベル/MIDI/MusicXML は可） | **禁止** | 記載なし |
| 学習済みモデルの配布 | 記載なし（DB 再頒布は禁止） | 成果物配布時は**利用規約の同梱が必須** | 記載なし |
| 生成音声の商用利用 | **事前問い合わせが必要** | 個人・法人とも**許可が必要** | **可**（商用・非商用を問わず） |
| クレジット表記 | **必須**（DB 利用が分かる表記） | **必須**「歌声DB制作:アマノケイ 音声提供者: 霧野蒼太」 | **不要** |
| その他の禁止 | 信用・品位を損なう行為、権利侵害、攻撃目的、法令違反 | 犯罪助長、信用・品位を損なう行為、著作権者の偽称 | ほぼ無し（犯罪利用のみ別途許諾） |

**夏目悠李の注（重要）:** 規約は「本データベースを利用して制作した成果物から**生成された音声を
機械学習用のデータとして用いること**」を禁止しています。また TALQu については「本モデルをベースと
した転移学習やファインチューニングで新たなモデルを生成すること」を禁じています。歌声 DB 自体は
ENUNU / NNSVS 向けに配布されており歌声合成モデルの学習が想定用途ですが、**SVC がその想定に含まれ
るかは規約から読み取れません。要ユーザー判断: 権利者への確認が必要です。**

### この台帳から読み取れること

**確認済み:** 3 DB とも、**DB そのものの再頒布は禁止または記載なし**です。学習済みモデルの重みが
「DB の再頒布」に当たるかは、どの規約にも明示されていません。

**確認済み:** 生成音声の商用利用は、波音リツのみ無条件で可、他 2 つは事前の許可・問い合わせが
必要です。**現時点で 3 DB すべてを含むモデルを商用配布できる状態ではありません。**

**要ユーザー判断:**

1. 学習済みモデルを配布するのか、手元で使うだけなのか。配布するなら 3 DB それぞれに確認が要ります。
2. 商用利用の予定があるか。あるなら御丹宮くるみと夏目悠李への問い合わせが M0 の完了条件に入ります。
3. **SVC 特有の論点**: SVC は「任意の歌唱を target singer の声に変換する」ものです。これは
   SVS（譜面から歌わせる）と用途が異なり、どの規約も明示的に想定していません。少なくとも
   夏目悠李については確認が必要です。

## 2. SVC で新たに必要になるもの

**未実装:** 以下はまだ決まっていません。M0 はここが埋まるまで完了しません。

| 必要なもの | 状態 | 備考 |
|---|---|---|
| target singer | **未定** | 上記 3 名から選ぶか、別途用意するか。[データと計算資源](svc-data-compute.md) の目安は 5〜10 時間 |
| multi-singer corpus | **未定** | 同 20〜50 人 / 100〜300 時間。3 DB では話者数が足りない |

**注意:** 未知 source singer の test set は、multi-singer corpus と**同じ素材から取ってはいけません**。
学習に出た歌手を source にすると、汎化性能を過大評価します。

## 3. 記録すべき項目（各素材について）

[データと計算資源](svc-data-compute.md) 9 節の台帳項目です。素材が決まったら埋めます。

- dataset 名、version、入手元 URL、取得日、権利、許可用途、配布可否
- singer ID、曲 ID、take ID、収録条件
- original / separated / denoised の lineage
- checksum と preprocessing manifest
- reject reason と除外前後の時間
- split 作成 seed と split list
- pitch / loudness / duration の分布

## 4. 次にやること

1. **要ユーザー判断の 3 点**（配布形態・商用利用・SVC 用途の確認）を決める。決まらないと素材を
   確定できません。
2. 素材が決まったら、`tools/dataset/` の検査で clipping・sample rate・無音・DC offset を通し、
   除外したものを reject reason つきで残す（M0 ゴール 2）。
3. 音域と発声スタイルの coverage を集計する（M0 ゴール 3）。
4. 曲・収録セッション単位の split list を seed つきで作る（M0 ゴール 4）。

2〜4 の道具は素材が決まる前に作れるので、先に実装します。

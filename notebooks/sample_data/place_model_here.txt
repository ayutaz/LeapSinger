The LeapSinger acoustic model checkpoints are distributed as a GitHub Release asset,
not committed to this repository. To run the notebook:

  1. Download the release archive (LeapSinger_models.zip) and extract it.
  2. Copy one of the checkpoints into this folder, for example:
         notebooks/sample_data/3speaker_gan2d.pth
  3. Make sure the notebook's PTH variable points to that file.

Checkpoints placed here are ignored by git, so they will not be committed.
